# Chapter 2 artifacts

This directory stores small, curated inputs and outputs used by the chapter.

## Artifact classes

- Local deterministic artifacts: scheduler/allocation simulation data and plots
- GPU environment artifacts: exact model, software, hardware, and server config
- Raw serving artifacts: one JSONL record per request and Prometheus snapshots
- Derived serving artifacts: CSV/JSON summaries and generated charts

## Reproducibility requirements

Every GPU artifact set must identify:

- UTC timestamp and run ID
- Model and tokenizer IDs with immutable revisions
- Python, vLLM, PyTorch, Triton, CUDA, driver, and Modal versions
- GPU model/count and relevant memory
- Full `vllm serve` command and environment
- Workload version, seed, arrival model, token-length distributions, and sample
  count
- Warmup, exclusion, retry, timeout, and failure handling
- Script and artifact-schema versions

Raw request records must be preserved before aggregation. Generated charts must
be reproducible from committed raw or derived data.

## Current deterministic artifacts

- `scheduler-simulation.json`: request, timeline, utilization, and completion
  accounting for static and continuous batching
- `scheduler-timeline.csv`: one row per policy, iteration, and batch slot
- `scheduler-simulation.png`: timeline generated from the same simulation
- `allocator-simulation.json`: capacity accounting for contiguous reservation
  and fixed-size paged allocation
- `allocator-records.csv`: per-request allocation records
- `allocator-simulation.png`: used, wasted, and free KV token slots

Regenerate these CPU-only artifacts from the repository root:

```bash
uv run python chapters/02-serving-with-vllm/code/vllm_local_artifacts.py
```

The simulations isolate the mechanisms being taught. They are not vLLM
benchmarks or reimplementations of the vLLM scheduler, KV manager, or kernels.

## Remote-run policy

GPU artifacts are generated only after local tests pass, current Modal spend is
checked, worst-case cost is estimated, and the author approves that exact run.
They are never silently regenerated by tests.

No GPU artifacts have been generated for Chapter 2 yet.
